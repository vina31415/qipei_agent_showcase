# ADR-06：交期计算与人工确认红线

- 状态：已接受
- 日期：2026-07-14

## 上下文
需确定交期计算方式，并明确最终交期采纳权归属，防止业务员插单。

## 决策
1. 交期全自动计算：现货 / 在途 / 采购周期组合。
2. 输出附插单风险提示。
3. 红线：最终交期采纳权在人，agent 只算 + 提示，不自动落交期。

## 理由
- 三输入数据齐全可算（实际数据源见 ADR-17）。
- 交期牵动工厂排单，怕业务员插单，采纳权必须保留在人。

## 后果
- 交期输入字段名由 ADR-17 定稿（在途来自 PIM PO，采购周期/供应商交期来自金蝶）。
- 红线靠流程设计约束，不靠技术硬约束（agent 不提供写交期工具）。

---

## 作者批注：为什么做这个决策

这条红线的来源是和业务方聊出来的一个真实恐惧：业务员为了成交会承诺不切实际的交期，如果 agent 自动把算出来的交期写回系统，插单就没人拦得住。技术上完全可以做到自动落库（数据都是齐的），但"能做"不等于"该做"——agent 的责任边界是算清楚、提示风险，采纳权留在人。这是我在这个项目里学到的最重要的一课：**企业级 agent 的信任不是技术问题，是权责设计问题。**
