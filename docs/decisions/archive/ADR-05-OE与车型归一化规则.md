# ADR-05：OE 与车型归一化规则（方向）

- 状态：已接受（方向，具体规则由 ADR-15 定稿）
- 日期：2026-07-14

## 上下文
OE 号存在前缀/分隔符/大小写/补零等格式变体，车型适配为文本，需确定归一化规则。

## 决策
1. OE 归一化覆盖四类变体：前缀、分隔符、大小写、补零。
2. 车型适配文本需清洗 + 实体归一化（make/model/year/engine），不可原样使用。
3. 归一化规则落成配置表，不硬编码。

## 理由
- 30% 对不上大头是格式差异，归一化后精确命中。
- 车型文本直接检索会乱召回、错配配件，必须转实体。

## 后果
- 前缀清单、补零位宽等细节需业务方确认后落配置（已由 ADR-15 定稿：实际无固定位宽，弃补零，改去前导零 + 两模式检索）。
- 车型实体结构由 ADR-21 定稿（PIM 已是结构化字段，仅需 brand 归一化）。
