# ADR-27：交期计算细节与插单风险规则（细化 ADR-17）

- 状态：已接受
- 日期：2026-07-20

## 上下文
需确定多笔在途 PO 的取值、默认供应商判定字段、以及插单风险规则，使 calc_lead_time 可正确实现与测试。

## 决策

### 多笔在途 PO 取值
1. 按 FPLANARRIVALDATE 升序排序，优先取最早到货 PO 作为主交期。
2. 同时返回全部在途 PO 列表给业务员（提示「还有其他在途订单，到货时间 XX」）。
3. 最早 PO 数量无法覆盖本次询价数量 → 拆分计算：在途能满足部分按 PO 到货日；缺口部分走采购周期 + 供应商交期。

### 现货不足拆分
现货数量 < 询价数量时：现货部分按现货交期（默认 1 天），缺口部分走「在途 → 采购」分支计算。

### 默认供应商判定
- 金蝶 BD_MATERIAL 关联物料供应商表 BD_MATERIALSUPPLIER，判定字段 FISDEFAULTSUPPLIER（1=默认）。
- 有默认供应商 → 取默认供应商 FLEADTIMESUPP。
- 无默认供应商 → 取所有有效供应商里最短交期作推荐交期，标注【非默认供应商，存在供货风险】。

### 插单风险规则
1. 选用非默认供应商 → `risk_level: medium`
2. 询价需求量 > 该供应商历史月度最大供货量 → `risk_level: high`
3. 采购交期 > 30 天 → 附加长周期风险提示
4. risk 标签随交期返回，不阻断查询，由业务员确认是否接单。

## 理由
- 多笔在途按最早到货 + 缺口拆分，既给出可承诺交期又暴露缺口，避免一刀切。
- 风险分级不阻断查询，把「是否接单」留给业务员，符合 ADR-06 采纳权在人。

## 后果
- calc_lead_time 输出需含：主交期、全部在途 PO、供应商、risk_level、长周期提示。
- stock 表需扩展：在途到货日、未收数量、供应商、默认供应商标志、采购周期、供应商交期、物料级现货交期覆盖字段。
