# ADR-18：WhatsApp 渠道 BSP 选型（后置）

- 状态：已接受（后置，非 M1）
- 日期：2026-07-17

## 上下文
需确定 WhatsApp 渠道（后置）的对接方式与 BSP 选型。

## 决策
1. WhatsApp 渠道经 BSP 对接：BSP 提供 REST API 发消息 + Webhook 收上行，智能体作为后端业务服务，不直接对接 Meta Graph API。
2. BSP 优先备选：360dialog。

## 理由
- 走 BSP 省去 Meta 底层对接与合规复杂度，智能体只关注业务。

## 后果
- M1 不实现；渠道层预留 BSP 适配器接口。

## 待确认
- 数据流描述中的「客户 WhatsApp」与 ADR-01「不直接面对客户」存在矛盾：该渠道建成时面向内部员工还是外部客户，需澄清（若对外，需重新设计鉴权与数据隔离，另立 ADR）。
