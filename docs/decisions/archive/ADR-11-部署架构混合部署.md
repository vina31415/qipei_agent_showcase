# ADR-11：部署架构——混合部署（数据内网 + 应用云）

- 状态：已接受
- 日期：2026-07-15

## 上下文
需确定系统部署拓扑。约束：核心业务数据不直接公网暴露。

## 决策
1. 混合部署：数据层（金蝶 ERP、PIM、库存、交期、客户报价、OE / 车型主数据）全部保留内网，不直接公网暴露。
2. 业务智能体应用层（编排层 + 渠道层）优先云上部署。
3. 提供纯内网备选方案（应用层亦可整体下沉内网）。

## 理由
- 数据敏感（客户报价 / 库存），必须留在内网；LLM（豆包）为云端 API，编排层天然适合云上。
- 云上只跑「无状态大脑」（意图 / 调度），内网跑「数据 + 确定性能力」，边界清晰、泄密面最小。

## 后果
- 能力层 + 集成层 + 产品主数据中心（MySQL）部署在内网；云上编排层经安全通道（ADR-12）调用内网能力层 API。
- 敏感数据不出网到 LLM（ADR-13），回答由模板拼接。
- 目录结构区分「内网侧 / 云侧」两套部署单元。
- 纯内网备选触发时，豆包需替换为私有化 LLM（另立 ADR）。
