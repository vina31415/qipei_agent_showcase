# ADR-01：智能体定位与范围边界

- 状态：已接受
- 日期：2026-07-13

## 上下文
需明确智能体面向谁、做到哪一步。B2B 汽配售后工贸工厂，团队含业务员、跟单员、仓库、售后客服。

## 决策
1. 智能体**对内服务**四类角色，不对外、不直接面对客户。
2. 所有渠道（ERP/CRM 内嵌、WhatsApp）均为「内部助手」形态。
3. 第一里程碑范围：对话式 OE 查询 + 车型查询（含库存/价格/交期）。
4. 后置：VIN 查询、报价单草稿、非结构化知识库、全自动写操作。

## 理由
- 不对外 → 无对外鉴权、无多客户数据隔离口径，安全模型大幅简化，项目可控。
- 收窄到 OE/车型查询 → 单场景做透，价值最直接、风险最低。

## 后果
- 后续若扩展到对外服务，需重新设计鉴权与数据隔离（另立 ADR）。
