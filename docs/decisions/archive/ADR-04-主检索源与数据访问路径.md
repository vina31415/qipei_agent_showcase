# ADR-04：主检索源与数据访问路径

- 状态：已接受
- 日期：2026-07-13

## 上下文
金蝶 `executeBillQuery` 原生只返回标准字段，OE 号/车型适配为 BOS 自定义字段读不到。PIM 可拉 OE，车型适配为文本需清洗。

## 决策
1. 主检索源 = 清洗归一化后的 PIM 产品库（产品主数据中心）。
2. 金蝶只出 SKU/库存/价格。
3. ERP 现有 OE 模糊检索（公司二开）降级为兜底数据源，主检索 miss 时触发。

## 理由
- 数据可用性：OE/车型只能从 PIM 拿到可读数据。
- 检索质量：清洗归一化后的 PIM 才能精确命中，ERP 模糊检索仅兜底防漏召回。

## 后果
- 需建设 ETL：PIM + 金蝶 → 产品主数据中心。
- 车型适配的实体归一化是独立数据工程，需排期。
