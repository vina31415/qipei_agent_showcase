# ADR-40 分层 mock 测试策略（默认工程约定）

日期：2026-07-24

## 决定
单元测试对不可控外部依赖（LLM / 网络 / 时钟 / 随机）一律 mock；本地文件 IO 依赖注入 + `tmp_path` / 内存 fake 测真实读写；存在外部 API 依赖（金蝶 / PIM）时用 fixture 锁响应结构。

## 理由
保证测试全可 mock、可离线跑、不依赖真实外部系统，稳定且可复现；fixture 锁结构可防止外部 API 响应字段漂移导致误判。

## 影响与代价
- 开发须为 LLM/金蝶/PIM 等外部调用提供可注入的抽象（呼应 ADR-41）。
- 测试资产需维护外部 API 的响应 fixture。
