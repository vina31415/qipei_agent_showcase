# ADR-43 依赖版本下限约束

日期：2026-07-24

## 决定
spec §3.6 依赖清单补主/次版本下限约束：`fastapi>=0.110`、`uvicorn>=0.29`、`pydantic>=2.6,<3`、`httpx>=0.27`、`sqlalchemy>=2.0,<3`、`pymysql>=1.1`、`volcengine>=1.0`、`pydantic-settings>=2.2`、`redis>=5.0`、`pytest>=8.0`、`ruff>=0.4`。不写死 `==`。

## 理由
满足「关键第三方库含版本约束」的决策清单要求；下限取各库稳定版本，保证可复现又不被锁死。

## 影响与代价
- CI/开发环境按上述下限安装；如需收紧由后续锁文件（如 uv.lock）承载，不在 spec 层写死。
