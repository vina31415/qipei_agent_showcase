# ADR-12：云 ↔ 内网安全通道——反向隧道 / 安全网关

- 状态：已接受
- 日期：2026-07-15

## 上下文
云上编排层需调用内网能力层 API，需打通一条不暴露内网数据的安全通道。业务方内网已有网关。

## 决策
采用反向隧道 / 安全网关（方案 B）：内网侧主动出连到云，通过安全网关暴露只读 API，内网不开入站端口。

## 理由
- 内网零入站暴露：不对外开端口，泄密面最小。
- 复用已有内网网关，运维简单、成本低；相比 VPN / 专线无需额外组网。
- 只读、单向：云侧仅能调用内网暴露的白名单 API，无法反向进内网系统。

## 后果
- 能力层 API 需经网关鉴权 + 白名单，仅暴露给编排层所需的最小接口集。
- 需定义网关鉴权方式（token / mTLS），落于配置项。
- 若未来并发 / 带宽成为瓶颈，再评估专线升级（另立 ADR）。
