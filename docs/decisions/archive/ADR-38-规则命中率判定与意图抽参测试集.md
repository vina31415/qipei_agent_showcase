# ADR-38：规则命中率判定与意图/抽参测试集

- 状态：已接受
- 日期：2026-07-22

## 上下文
成功标准「规则命中率 ≥95%」需可测，需定义测试语料、判定标准、统计口径。

## 决策

### 判定标准
- 意图正确 且 参数完全正确（OE 归一化后精确匹配 / 车型 brand+series+model+year 全对 / 数量对）→ 计为命中。
- 任一参数错、漏 → 计为未命中（触发 LLM 兜底）。

### 测试语料（M1 至少 200 条，覆盖）
- OE 查询：纯数字 / 字母数字 / 带前缀（OE:/OEM:/REF:）/ 带分隔符（空格/横杠/斜杠）/ 带前导零 / 带版本后缀
- 车型查询：品牌中文/英文/缩写、车系+车型、年份（含缺年份）、组合（OE+数量）
- 交期查询：SKU + 数量
- 负面：模糊 / 多意图 / 无法解析

### 统计口径
- 规则命中率 = 规则路径命中条数 / 总条数 × 100%
- 验收：规则命中率 ≥95%；抽样集由 26 条 OE 样本 + 业务补充语料构成，固化为 pytest 参数化用例。

## 理由
- 明确判定口径，P95≤3s 与规则命中率≥95% 才可联合验收。

## 后果
- 测试语料落 `tests/intent_corpus.yaml`；param_extract 的规则命中率测试据此断言。
