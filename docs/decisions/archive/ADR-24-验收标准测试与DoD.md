# ADR-24：验收标准、测试要求与完成定义

- 状态：已接受
- 日期：2026-07-20

## 上下文
需确定功能验收标准、测试要求与完成定义，供 Coding Agent 自检与验收。

## 决策

### 功能验收标准（每条可判定，落 spec §4.1）
- OE 检索：端到端命中率 ≥98%（含兜底）；无结果明确提示并触发 ERP 兜底
- OE 归一化：26 条样本 + 前缀/分隔符/前导零/大写变体，结果与预期一致
- 车型检索：brand+model+year 返回适配 SKU；year 落区间；brand 经映射
- 库存：返回 FAVAILABLEQTY
- 分级价：BD_PriceBase 有效价（FISACTIVATE=1 且有效期覆盖今天）；miss 降级 FPRICE
- 交期：现货→1 天；在途→FPLANARRIVALDATE−今天；否则→FLEADTIME(15 天兜底)+FLEADTIMESUPP(默认供应商，无则最长)；附供应商备注
- 权限：仓库查同一 SKU，价格字段不出现
- 红线：任何查询零写操作（金蝶/PIM 无写入调用）
- 响应：端到端 P95 ≤3 秒

### 测试要求
- 框架 pytest；能力层/集成层核心逻辑行覆盖 ≥80%
- 必测场景：OE 归一化、brand 归一化、检索命中/未命中/兜底、交期三分支+供应商取值、权限过滤、集成层 mock(429/token 刷新)、编排层 LLM mock(失败降级)

### 完成定义 DoD
代码完成 + pytest 全绿（覆盖率≥80%）+ ruff 无告警 + 关键操作审计留痕

## 理由
- 验收标准由 ADR-09 成功标准派生，逐条可判定，供 Coding Agent 自检与验收。

## 后果
- 验收标准落 spec §4，作为测试用例与验收依据。
