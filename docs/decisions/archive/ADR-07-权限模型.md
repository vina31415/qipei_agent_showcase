# ADR-07：权限模型

- 状态：已接受
- 日期：2026-07-14（2026-07-17 补全矩阵）

## 上下文
价格、供应商与交期信息敏感，需按角色控制数据可见性。

## 决策

### 权限矩阵
| 数据 | 业务员 | 跟单 | 售后 | 仓库 |
|---|---|---|---|---|
| SKU / 品名 / 车型 / 图片 / OE | ✓ | ✓ | ✓ | ✓（拣货核对） |
| 库存（现货 + 库位） | ✓ | ✓ | ✓ | ✓ |
| 分级价 | ✓ | ✓ | ✓ | ✗ |
| 主交期 lead_time | ✓ | ✓ | ✓ | ✗ |
| 备选供应商交期 | ✓ | ✓ | ✗ | ✗ |
| 供应商备注 | ✓ | ✓ | ✗ | ✗ |

横切层统一拦截，能力层返回前过滤。

### 角色职责区分
- **业务员 / 跟单**：全量（报价需参考供货风险，跟单需跟进订单）。
- **售后**：可见主交期（对接终端客户、回复发货时间），隐藏供应商备注、备选供应商交期（采购/议价敏感，售后不参与）。
- **仓库**：仅库存、SKU、品名、库位、图片、车型适配（拣货/验货二次校验防发错件），隐藏所有交期、价格、供应商备注、客户等级等报价信息。

### 供应商备注敏感判定
供应商备注属**业务敏感信息**（含供应商产能、起订量、议价底价、交期坑点），仅业务员、跟单可见。

## 理由
- 价格与供应商信息敏感，需在单一位置强制权限，避免各工具各自实现遗漏。
- 「最终对外承诺的主交期放开；供应商侧底层备选与内部备注屏蔽」，按角色职责最小授权。

## 后果
- 权限策略配置化（落 `config/permission.yaml`），新增角色仅改配置。
- 能力层各工具按 role 过滤返回字段。
