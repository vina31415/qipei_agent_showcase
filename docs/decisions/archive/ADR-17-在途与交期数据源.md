# ADR-17：在途与交期数据源（修正 spec §11）

- 状态：已接受
- 日期：2026-07-16

## 上下文
spec §11 原设「现货 / 在途 / 采购周期三输入均更新于金蝶」。经业务方 IT 提供实际接口后确认：在途数据不在金蝶物料，而在 PIM 自研后台的采购订单（PO）。

## 决策
交期 = 有现货 ? 现货交期 :（有在途 ? 在途交期 : 采购周期 + 供应商交期），各输入数据源：

| 输入 | 数据源 | 字段 / 取值 |
|---|---|---|
| 现货 | 金蝶 BD_MATERIAL | FAVAILABLEQTY（可用量） |
| 现货交期 | 全局配置表（物料自定义字段可覆盖） | 默认 1 天（次日发货）；0 天仅特殊加急单单独标记 |
| 在途 | PIM 采购订单 | FNOTRECEIVEQTY > 0（FDOCUMENTSTATUS=C） |
| 在途交期 | PIM 采购订单 | FPLANARRIVALDATE − 今天 |
| 采购周期 | 金蝶 BD_MATERIAL | FLEADTIME；空值兜底 15 天（全局配置） |
| 供应商交期 | 金蝶 BD_SUPPLIERMATERIAL | FLEADTIMESUPP（物料+供应商维度） |

### 供应商交期取值规则
1. 取【默认供应商】的交期（业务以实际下单供应商为准，不取最短避免虚承诺，不取最长避免丢单）。
2. 物料未维护默认供应商时，降级取所有供应商交期里【最长值】（保守）。
3. 返回交期结果附带备注「该交期取自 XX 供应商」；有多个备选供应商时可一并展示其他供应商交期作参考，但计算只用上述规则。

## 理由
- 现货 1 天：拣货/复核/打包需当天处理，外贸极少当日出库。
- 采购周期兜底 15 天：FLEADTIME 缺失时给保守默认，可后台调整。
- 默认供应商：交期预测以实际下单供应商为准，兼顾承诺真实性与成交率。

## 后果
- 交期计算跨源组合：金蝶（现货/采购周期/供应商交期）+ PIM PO（在途）。
- 集成层金蝶适配器封装 BD_MATERIAL（含 FLEADTIME）与 BD_SUPPLIERMATERIAL 查询；PIM 适配器封装 PO 在途。
- 现货交期 1 天、采购周期兜底 15 天落 config，spec §5 汇总表显式写出。
- calc_lead_time 工具输出须含供应商备注与备选供应商交期（参考）。
